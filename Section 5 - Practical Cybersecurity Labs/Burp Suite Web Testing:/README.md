# Burp Suite Web Application Testing

## Overview

This lab introduced Burp Suite for web application security testing using the OWASP Juice Shop application.

## Skills Demonstrated

- HTTP Request Analysis
- Proxy Interception
- Request Manipulation
- Repeater Usage
- Web Application Enumeration
- SQL Injection Testing

## Tools Used

- Burp Suite
- Docker
- OWASP Juice Shop
- Kali Linux

## Highlights

- Intercepted and analyzed HTTP traffic
- Modified requests using Burp Repeater
- Tested application inputs for SQL injection weaknesses
- Explored common web application attack surfaces
