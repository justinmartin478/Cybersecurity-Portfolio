# Professional Penetration Testing Capstone

## Overview

This capstone assessment involved performing a full security assessment against a vulnerable target system. The objective was to identify weaknesses, gain access through multiple attack paths, and ultimately retrieve the target flag while documenting findings and remediation recommendations.

## Skills Demonstrated

- Network Discovery
- Nmap Enumeration
- FTP Exploitation
- Wireshark Analysis
- Steganography
- SSH Access
- Hydra Password Attacks
- Metasploit
- Reverse Shell Creation
- Security Documentation

## Tools Used

- Kali Linux
- Nmap
- Wireshark
- Hydra
- FTP
- SSH
- Metasploit
- Stegcracker

## Highlights

- Discovered hidden credentials using steganography techniques
- Retrieved and analyzed packet captures
- Performed credential attacks using Hydra
- Established remote access through multiple vectors
- Generated security recommendations and mitigation strategies
