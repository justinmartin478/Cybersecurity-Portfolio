# How Many Shells?

## Overview

This lab focused on identifying and exploiting multiple access vectors against a Metasploitable 3 target machine.

## Outcome

- Gained SSH access to the Metasploitable 3 target using discovered credentials.
- Exploited EternalBlue (MS17-010) to obtain a reverse shell.
- Enumerated FTP services and recovered hidden data through steganography investigation.

## Skills Demonstrated

- SSH Access
- FTP Enumeration
- SMB Exploitation
- EternalBlue (MS17-010)
- Metasploit
- Steganography Investigation

## Tools Used

- Kali Linux
- Metasploit
- SSH
- FTP
- Stegcracker

## Highlights

- Established SSH access using discovered credentials
- Exploited EternalBlue to gain a reverse shell
- Accessed FTP services and enumerated files
- Investigated web hosted content for hidden information

## Lessons Learned

This lab reinforced the importance of strong authentication controls, patch management, and layered defenses.
