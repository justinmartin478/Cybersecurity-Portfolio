# Local File Inclusion & Remote File Inclusion

## Overview

This lab explored web application vulnerabilities involving Local File Inclusion (LFI) and Remote File Inclusion (RFI) using the Damn Vulnerable Web Application (DVWA).

## Outcome

- Retrieved sensitive system files through Local File Inclusion (LFI).
- Modified PHP configuration and hosted a payload to enable Remote File Inclusion (RFI).
- Achieved remote code execution via a PHP reverse shell and Netcat listener.

## Skills Demonstrated

- Docker Deployment
- DVWA Configuration
- Local File Inclusion
- Remote File Inclusion
- Reverse Shell Deployment
- PHP Configuration
- Netcat Listeners

## Tools Used

- Kali Linux
- Docker
- DVWA
- Netcat
- Python HTTP Server
- PHP Reverse Shell

## Highlights

- Retrieved sensitive system files through LFI
- Modified PHP configuration to support RFI testing
- Hosted and executed a PHP reverse shell
- Demonstrated remote code execution through vulnerable web functionality
