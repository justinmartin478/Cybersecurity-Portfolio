⚡️ PowerShell Scripting Essentials — Cheat Sheet

Command / Syntax                    | Meaning                                          | Example
------------------------------------|--------------------------------------------------|-----------------------------------------------
Get-Help Name[-Detailed|-Online]    | Built-in help for a cmdlet/function              | Get-Help Get-Process -Detailed
Verb-Noun [-Parameter value]        | Cmdlet naming pattern                            | Get-Service -Name spooler
$var = value                        | Create/assign variable                           | $user = "Justin"
$( … )                              | Subexpression (evaluate expression in a string)  | "Now: $(Get-Date)"
"double quotes $expand"             | Interpolated string (variables/$(… ) expand)     | "Hello $user"
'single quotes $literal'            | Literal string (no expansion)                    | 'Hello $user'
@' … '@ / @" … "@                   | Here-string (multi-line text)                    | @'line1\nline2'@
Write-Output                        | Send objects to pipeline (preferred)             | Write-Output $user
Write-Host                          | Print to screen only (non-pipeline)              | Write-Host "Hi" -ForegroundColor Cyan
# comment                           | Line comment                                     | # this is a comment
` (backtick)                        | Escape / line continuation (avoid when possible) | "quote`"d"
-join / -split                      | Join or split strings                            | "a","b" -join "+"
-f (format operator)                | Composite format strings                          | "{0:yyyy-MM-dd}" -f (Get-Date)
$PSVersionTable.PSVersion           | Show PowerShell version                          | $PSVersionTable

Command/Syntax                      | Meaning                                          | Example
------------------------------------|--------------------------------------------------|-----------------------------------------------
… | Select-Object Prop,…            | Choose properties                                | Get-Process | Select Name, Id
… | Where-Object { $_.Prop -op Val }| Filter objects                                   | Get-Service | Where { $_.Status -eq 'Running' }
… | ForEach-Object { … }            | Process each object                              | Get-ChildItem *.log | ForEach { $_.Length }

Measure-Object                      | Sum/Count/Avg                                    | gci *.txt | Measure Length -Sum

⚡️ Tips

- Prefer **Write-Output** for script results (keeps things pipeline-friendly). Use **Write-Host** only for UI messages.
- Use **double quotes** for strings that need `$variable` or `$(command)` expansion; single quotes for literals.
- Avoid ending a line with a backtick (**`**). It escapes the newline and often causes “Incomplete string token.”
- Use **$()** subexpression to run commands inside strings; e.g., `"Time: $(Get-Date)"`.
- Use **-WhatIf** and **-Confirm** on destructive commands (Remove-Item, Stop-Process, etc.).
- Use **Set-StrictMode -Version Latest** in learning scripts to catch bad habits early.
