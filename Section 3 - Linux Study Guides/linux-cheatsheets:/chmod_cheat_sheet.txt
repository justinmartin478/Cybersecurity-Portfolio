===============================================
🔐 LINUX CHMOD PERMISSION CHEAT SHEET
===============================================

📊 PERMISSION VALUES:
  r = 4   w = 2   x = 1

🔢 NUMERIC (OCTAL) EXAMPLES:
  600 → rw-------   (User: rw, Group: -, Others: -)
  644 → rw-r--r--   (User: rw, Group: r, Others: r)
  700 → rwx------   (User: rwx, Group: -, Others: -)
  755 → rwxr-xr-x   (User: rwx, Group: r-x, Others: r-x)
  777 → rwxrwxrwx   (Everyone full access ⚠️)

🔣 SYMBOLIC EXAMPLES:
  chmod u+x file         → Add execute to user
  chmod g-w file         → Remove write from group
  chmod o+r file         → Add read to others
  chmod u=rw,g=r,o= file → Set exact permissions

💡 TIPS:
  - Directories need 'x' to cd into.
  - Avoid 777 on sensitive files.
  - Combine numeric & symbolic as needed.
